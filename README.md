# Kalman Filter Steps

An offline Android app for learning Kalman filtering and state estimation at a slow pace.

The course has 8 modules and 32 lessons, in this order:
1. Probability refresher
2. Estimation basics
3. The 1D Kalman filter
4. The multivariate Kalman filter
5. Practice (consistency, tuning, Joseph form, gating)
6. Nonlinear filters (EKF, UKF, particle filter)
7. Sensor fusion (complementary filter, GPS/INS, RTS smoother)
8. Applications (LQG, battery state of charge, trend models)

The app includes formulas, tables and quizzes, plus these simulations:
- Gaussian fusion
- A scalar Kalman filter with Q/R tuning and an NIS check
- 2D target tracking
- A particle filter localizing a robot in a corridor
- A complementary tilt filter

Progress tracking covers your streak, a daily goal, charts and a list of lessons worth reviewing.

GitHub Actions builds the APK. Download it from the **Releases** page.
